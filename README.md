# ScamChain Nexus — Beyond Binary

ScamChain Nexus is a privacy-first cybersecurity investigation prototype for exploring suspicious messages and scam workflows. It provides guided simulations, explainable browser-side checks, evidence intake, entity/timeline correlation, a reviewable attack graph, an evidence ledger, and a protection center.

## Live demo

Once the GitHub Pages workflow completes: https://lynxiecreations-crypto.github.io/ScamChain-Nexus/

## Important limitations

This is a prototype. Browser-side heuristic checks are not a production antivirus or a validated fraud-probability model. Demo scenarios are fictional, risk scores are indicative rather than calibrated probabilities, and forensic/stylometry features are not proof of identity or attribution. Do not submit real secrets or sensitive evidence to a public demo.
